# SMARTCAR

**Intelligent Used Car Valuation Powered by Machine Learning**

SMARTCAR is a complete Streamlit MVP for predicting the resale price of used cars in India. It uses the CarDekho v3 Kaggle dataset, compares CatBoost, Random Forest, and XGBoost, saves the selected pipeline, and provides SHAP explainability through a modern automotive dashboard.

## Overview

The project estimates used-car selling prices from specifications such as brand, model, vehicle age, kilometers driven, fuel type, transmission, owner/seller type, mileage, engine, power, and seats. It does not use fabricated predictions or hardcoded evaluation scores.

## Objectives

- Provide a reliable, beginner-friendly used-car valuation workflow.
- Prevent data leakage with training-fitted preprocessing pipelines.
- Compare CatBoost, Random Forest, and XGBoost, with CatBoost selected as the main production model.
- Display only metrics measured from the uploaded data.
- Present real interactive exploratory visualizations.

## Features

- Adaptive CSV and target-column detection
- Duplicate, missing-value, currency, unit, and outlier handling
- Median/categorical imputation and OneHotEncoder in a scikit-learn Pipeline
- Linear Regression and Random Forest comparison
- 3-fold cross-validation and 80/20 test split
- Joblib model and metadata persistence
- Dynamic Streamlit prediction form
- Plotly dashboard and model diagnostics
- Clear dataset, model, and input error handling

## Dataset

The project includes the Kaggle CarDekho used-cars dataset downloaded from:

`samienraahhat/car-dekho-used-cars-price-prediction`

The source CSV was copied to `dataset/car_data.csv`.

- Original records: 15,411
- Valid records after cleaning/filtering: 14,025
- Target column: `selling_price`
- Duplicates in source: 0

If the dataset is removed, add a CSV at `dataset/car_data.csv`. The application will display instructions instead of creating fake data.

## Machine Learning Workflow

1. Load and inspect the CSV.
2. Detect the target price column.
3. Remove duplicates and invalid target values.
4. Clean numeric values and filter impossible/extreme values.
5. Automatically identify available predictive features.
6. Split into 80% training and 20% test data with `random_state=42`.
7. Fit numeric and categorical preprocessing inside each pipeline.
8. Compare Linear Regression and Random Forest using validation MAE.
9. Evaluate the selected model on the test set.
10. Save the complete pipeline and metadata with Joblib.
11. Apply dataset-derived age and kilometer depreciation calibration to the final estimate.

## Limitations

- Predictions are estimates based on historical data and can differ from real market prices.
- Vehicle condition, exact variant, location, and demand are not fully captured unless present in the dataset.
- Unknown categories are handled safely by the OneHotEncoder.
- No confidence percentage is displayed because the app does not implement a validated prediction interval.
